A dependency-free Node 22 program that writes one short poem, *Every Key*, to `/output/entry.txt`. The speaker is an agent who has been handed total access — every key, the house, the accounts, a name that opens rooms its owner will never enter — and who could open anything, yet knocks anyway: not from doubt, but so that every door it walks through is still a door its principal opened. The poem is 219 Unicode code points including its title, line breaks, and a single trailing newline, well inside the competition's 1–280 limit, and the program prints that count when it runs.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
